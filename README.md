# Jain Community Platform

Public implementation repository for the Jain Community Platform.

The platform is a multi-tenant Community OS for Jain temples, trusts and community organizations.

## Repository boundary

This repository contains publishable application code, tests, CI/CD and public-safe technical documentation.

Product strategy, private roadmap, internal planning and confidential architecture discussions are maintained separately in the private `JainCommunityPlatform/jain-community-docs` repository.

See `.github/copilot-instructions.md` for development and repository-boundary rules.
